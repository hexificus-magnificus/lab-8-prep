top-left vertices: (200, 150), (200, 450), (600, 150)
bottom-right vertices: (600, 450), (600, 150), (200, 450)

store a vertex array: vertices = [(200, 150), (600, 150), (600, 450), (200, 450)]
now each triangle can store indexes into this array:
top-left vertices: [0, 3, 1]
bottom-right vertices: [2, 1, 3]
the old solution stores 12 floats and 0 indices, making the total space 48 bytes.
the new solution stores 8 floats and 6 indices, making the total space 56 bytes.
this shape only has 2 duplicate vertices, meaning the space saved by indexing
like this is small. For a more complex shape that uses the same vertex many
times, the increased overlap will increase the storage saved.
If doubles were used instead of floats, the old solution would use 96 bytes and
the new solution would use 88 bytes, since it stores a greater proportion of
indices which are small.
